MeshCore Configuration Portal

Step-by-step documentation to provision your radio hardware and hook into local RF relays.

IMPORTANT CAVEAT FOR AMATEUR RADIO OPERATORS

These devices are operated in the 902-928 MHz band with maximum of 1 watt PEP at the antenna when omni directional and when operating directional, 1 watt maximum over all elements of the antenna not to exceed 1 watt ERP at 6 dBi gain, [FCC Part 15 15.247(b) 3,4 and (c)] which has a shared usage with not only Amateur Radio but other unlicensed as well as licensed services on a shared basis. In this shared band, these mesh devices are being operated as unlicensed, low-power devices under FCC Rules Part 15 in the ISM Band or "Industrial, Scientific and Medical Band", and as such, encryption is allowed when operated as a Part 15 unlicensed device. FCC Rules Part 97, which govern Amateur Radio, does not allow encryption, and as a station licensed by the FCC, stations identifying as Amateur Radio stations are not allowed to communicate with unlicensed stations operating in the shared ISM Band. If you are a licensed Amateur Radio operator, pick your ID carefully so that you are not confused for an Amateur Radio station communicating with unlicensed, Part 15 stations.

1. Firmware Flashing Guide (meshcore.io/flasher)

MeshCore handles client nodes and background infrastructure differently. Hardware behavior is determined entirely by whether you flash the companion or the repeater binary block to the device chip.

Web Serial Connection Requirements

Launch a browser supporting Web Serial interface actions (Chrome, Edge, or Brave) and navigate to the flashing utility workspace: meshcore.io/flasher.

Firmware Flash Procedure

  1. Hardware Select: Connect your LoRa radio to your computer via USB data cable and select your exact board layout model from the drop-down menu (e.g., Heltec V3/V4, Seeed Studio SenseCAP, RAK WisBlock).
  2. Role Assignment: Select Companion Bluetooth if you want the radio to link with your phone app, or select Repeater if building an unattended infrastructure mast.
  3. Wipe & Flash: Drop the device into bootloader mode, check the "Erase Flash" flag to wipe old partition schemes cleanly, and hit Flash to run the environment loader.

2. Companion Node Application Setup

Once a radio board is flashed with companion firmware, it will act as a local Bluetooth server to your companion client application.

Pairing to the Node

Launch the MeshCore app on your smartphone and tap Connect in the top header window. Select your active hardware from the Bluetooth radio pool list and enter the PIN displayed on the node screen (or fallback to 123456 for screenless card setups).

App Settings -> Radio Region

Navigate to your core radio configuration screen inside the phone application and lock the baseline region profile to apply standard NC channels automatically:

  • Radio Region Preset: USA/Canada (Recommended)
  • Frequency Configuration: 910.525 MHz
  • Bandwidth (BW): 62.5 kHz
  • Spreading Factor (SF): 7
  • Coding Rate (CR): 5

App Settings -> Channel List

Navigate to the Channels tab and add or join the following regional channels to hook into the community grid:

  • Group Chat: #ncmesh
  • Automated Bots: #bot
  • Weather Telemetry: #wx
  • Path & DX Testing: #test

App Settings -> Display Name

Locate the user node description card block to name your local device so tracking utilities can catalog signal hops across the network canvas:

  • Display Name: Name your node whatever you want (Emojis supported 🛰️)

3. Standalone Infrastructure Repeater Setup via Web Configurator

Flashed with the specialized Repeater firmware build, these nodes operate completely unattended. They turn off power-hungry smartphone Bluetooth chips to optimize processing loops and maximize battery retention on remote solar infrastructure masts.

Local USB Serial Configuration Setup

Because repeater builds shut down Bluetooth beacons, you cannot configure them through the phone app. Instead, you change settings directly over a wired connection right after flashing:

  1. Launch Configurator: Keep the device connected to your computer via USB data cable. On the flashing webpage (meshcore.io/flasher), tap the active Configure Device button that loads right after a successful flash (or use the standalone web portal at config.meshcore.io).
  2. Lock Local Region: Tap the Serial Port connection window and locate the regional parameters card block. Set the dropdown target to USA/Canada to load your 910.525 MHz frequency defaults automatically.
  3. Set Node Identifier: Under the system settings block, name your node whatever you want. You are completely free to use nicknames, custom callsigns, or functional descriptors (Emojis are supported 🌲).
  4. Save & Commit: Click Save Settings to commit your variables directly to the hardware memory bank, then safely unplug the board for deployment.

Placement & Node Deployment Best Practices

MeshCore relies on dedicated physical infrastructure rather than client-device signal flooding. Follow these hardware rules to ensure smooth traffic flow across counties:

  1. Line-of-Sight Placement: Secure your repeater node at high elevations—preferably on chimneys, poles, or in clear attics. Even modest elevation shifts completely change path discovery results.
  2. Solar Resilience: If deploying a remote solar-recharged enclosure, pair your device with an adequate battery capacity buffer to sustain 24/7 directed-path routines over rainy winter days.

Verify Connection

Once deployed, check your nearby companion nodes to confirm they can successfully route text messages through your new repeater's custom node ID marker.
